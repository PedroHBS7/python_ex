# TDE GitHub

Projeto desenvolvido para a atividade TDE 1 da disciplina de Raciocínio Algorítimco.

## Objetivo

Aprender os conceitos básicos de versionamento utilizando Git e GitHub, aplicando práticas como:

- criação de repositórios;
- commits organizados;
- utilização de branches;
- pull requests;
- merges;
- documentação básica.

## Tecnologias utilizadas

- Python
- Git
- GitHub
- Visual Studio Code
